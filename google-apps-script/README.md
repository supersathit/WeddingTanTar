# เชื่อมเว็บงานแต่งกับ Google Sheets

1. สร้าง Google Sheet สำหรับงานแต่ง แล้วเปิด **ส่วนขยาย (Extensions) > Apps Script**
2. คัดลอกโค้ดทั้งหมดจาก `Code.gs` ในโฟลเดอร์นี้ไปแทนโค้ดใน Apps Script แล้วบันทึก
3. เลือกฟังก์ชัน `setup` แล้วกด Run และอนุญาตให้สคริปต์เข้าถึง Sheets กับ Drive
   - สร้างแท็บ `RSVP` และ `Slips` ในชีตที่เปิดอยู่
   - สร้างโฟลเดอร์ส่วนตัว `TanTar Wedding - Slips` ใน Drive
   - รัน setup ซ้ำได้โดยไม่ลบข้อมูลเดิม
4. กด **Deploy > New deployment > Web app**
   - Execute as: **Me**
   - Who has access: **Anyone** เพื่อให้แขกส่งได้โดยไม่ต้องเข้าสู่ระบบ
   - ถ้าบัญชีองค์กรไม่มีตัวเลือก Anyone ให้ใช้บัญชีที่อนุญาตการเผยแพร่ Web app สาธารณะ
5. คัดลอก Web app URL ที่ลงท้าย `/exec` ไปใส่ค่า `GAS_URL` ใน `index.html`
6. เปิดเว็บผ่าน localhost หรือเว็บไซต์จริง แล้วทดลองส่ง RSVP และสลิปอย่างละรายการ ตรวจแถวในชีตและเปิดไฟล์ใน Drive ด้วยบัญชีเจ้าของ

เว็บจะแสดงว่าสำเร็จเมื่อได้รับคำยืนยันจาก Apps Script เท่านั้น หากตอบกลับไม่ได้จะเก็บข้อมูลที่กรอกไว้ให้ลองใหม่ รหัสรายการเดิมป้องกันแถวซ้ำเมื่อส่งข้อมูลเดิมซ้ำหลังการเชื่อมต่อขัดข้อง

ไฟล์สลิปไม่ถูกแชร์สาธารณะ ผู้ที่จะเปิดลิงก์ในชีตต้องมีสิทธิ์เข้าถึงโฟลเดอร์ Drive ด้วย ไม่ควรเผยแพร่ชีตที่มีชื่อและสลิปของแขกแบบสาธารณะ

เมื่อแก้ Code.gs ให้ไป **Deploy > Manage deployments > Edit > New version > Deploy** เพื่ออัปเดตโค้ดโดยใช้ URL เดิม

สำหรับเวอร์ชันรหัสอ้างอิง 5 หลัก ให้รัน `setup` อีกครั้งเพื่อเพิ่มคอลัมน์ `รหัสอ้างอิง` ใน RSVP (คอลัมน์ H) และ Slips (คอลัมน์ F) โดยข้อมูลเดิมยังอยู่ จากนั้น Deploy เวอร์ชันใหม่ รหัสเริ่มที่ 10000 และใช้ร่วมกันทั้งสองฟอร์ม ส่วน Request ID เดิมยังใช้ตรวจการส่งซ้ำภายใน ห้ามลบหรือรีเซ็ต Script Property `LAST_RECEIPT_ID` เพราะอาจทำให้รหัสซ้ำได้ ไฟล์สลิปใหม่จะชื่อ `10000_ชื่อ นามสกุล.jpg` (นามสกุลไฟล์ตามชนิดไฟล์) และชื่อในชีตจะตรงกับไฟล์ใน Drive ไฟล์เก่าจะไม่ถูกเปลี่ยนชื่อ

ระบบนี้ใช้โควตา Apps Script และ Drive ของเจ้าของบัญชี และ URL รับข้อมูลเป็นสาธารณะ ไม่มีระบบป้องกันสแปมขั้นสูง

## แสดงคำอวยพรบนเว็บไซต์

หลังวาง Code.gs เวอร์ชันนี้ ให้รัน `setup` อีกครั้งแล้ว Deploy เป็นเวอร์ชันใหม่โดยใช้ URL เดิม ระบบเพิ่มคอลัมน์ในแท็บ RSVP:

- I: `ยินยอมเผยแพร่` — บันทึกตามตัวเลือกของแขก
- J: `ชื่อที่แสดง` — ชื่อเล่นหรือชื่อที่แขกเลือกให้เผยแพร่

เว็บแสดงทันทีเมื่อ I เป็น TRUE และมีทั้งชื่อที่แสดงกับคำอวยพร โดยไม่ต้องอนุมัติ หน้าเว็บของผู้ส่งจะโหลดคำอวยพรใหม่หลังส่งสำเร็จ ข้อมูลเก่าที่ไม่มีความยินยอมไม่ถูกเผยแพร่ อย่าเปลี่ยนคอลัมน์ I เป็น TRUE แทนแขก คอลัมน์ K เดิม (ถ้ามี) จะไม่ถูกใช้งานแล้ว ดังนั้นรายการที่เคยยินยอมแต่รออนุมัติจะขึ้นเว็บด้วย หากต้องการนำข้อความออกให้ล้างข้อความคำอวยพรในคอลัมน์ G แล้วโหลดหน้าเว็บใหม่ ข้อความที่ผู้ชมโหลดไปแล้วจะยังอยู่จนกว่าจะโหลดหน้าใหม่

ระบบอ่านผ่าน Web app `?action=wishes` โดยส่งเฉพาะชื่อที่แสดงและคำอวยพร ล่าสุดสูงสุด 60 รายการ หน้าเว็บแสดงครั้งละ 3 การ์ด ไม่ต้องแชร์ Google Sheet ให้เป็นสาธารณะ

เอกสาร Google: https://developers.google.com/apps-script/guides/web
